# Аналих оттока клиентов банка

Исследование факторов, влияющих на отток клиентов, построение модели прогнозирования для выявления клиентов с высоким риском оттока

## О проекте

Проект направлен на анализ данных о клиентах банка для понимания причин оттока. Основная цель - выявить ключевые факторы, влияющие на решение клиентов уйти, 
и построить модель для прогнозирования оттока.

## Технологии

- Python
- Pandas - обработка и анализ данных
- Numpy - математические операции
- Matplotlib & Seaborn - визуализация
- Scikitlearn - построение моделей машинного обучения
